# kijige-studio.github.io

기지개스튜디오(Kijige Studio)의 GitHub Pages 사이트다. 앱 소개, 개인정보처리방침, 고객지원 페이지를 호스팅한다.

## 페이지 출처

- Snow Tail 원본은 `Snow-Tail/site`에 있다. 그곳에서 고친 뒤, 이 저장소의 같은 경로로 복사한다.
- 10p 페이지와 Kurtain 페이지는 원래 `hevinxx/10p-link`, `hevinxx/kurtain-site`에서 옮겼다.

## 주의 사항

- 예전 `hevinxx.github.io` 주소는 스토어 URL을 교체한 뒤에도 리다이렉트 스텁으로 영구 유지한다. 삭제하지 않는다.
- 사업자 정보는 `_data/business.yml` 한 곳만 수정한다. 모든 페이지 푸터에 반영된다.
- `app-ads.txt`는 AdMob용이다. 스토어 개발자 웹사이트를 이 도메인으로 바꾼 뒤에 유효하다.
