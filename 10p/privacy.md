기지개스튜디오(이하 "회사")는 모바일 앱 10p(Android·iOS, 이하 "서비스")를 운영합니다. 회사는 「개인정보 보호법」에 따라 이용자의 개인정보를 처리합니다. 이 방침은 회사가 어떤 개인정보를 왜 처리하고 어떻게 보호하는지 알려 드립니다.

- 시행일: 2026년 11월 25일

## 1. 처리 목적

회사는 아래 목적으로만 개인정보를 처리합니다. 목적이 바뀌면 미리 알리고 필요한 동의를 받습니다.

1. **서비스 제공:** 책장, 독서 기록, 메모, 목표 쪽수, 달력·통계를 저장하고 여러 기기에서 불러옵니다.
2. **회원 관리:** 이메일 계정 가입·로그인, 비밀번호 재설정, 회원 탈퇴를 처리합니다.
3. **서비스 개선:** 앱 이용 통계를 분석하고, 앱 오류를 찾아 고칩니다.

## 2. 처리 항목

### 가. 이용자가 직접 입력하는 정보

| 구분 | 항목 | 필수 여부 |
|---|---|---|
| 이메일 계정 가입 | 이메일 주소, 비밀번호 | 이메일 가입 시 필수 |
| 독서 기록 | 책 정보(제목, 저자, 출판사, 표지 이미지 주소, ISBN, 전체 쪽수), 읽기 상태와 날짜, 읽은 쪽 범위, 메모 내용, 목표 쪽수 | 기능을 쓸 때 입력 |

- 이메일 가입은 선택입니다. 가입하지 않아도 익명 계정으로 서비스를 모두 쓸 수 있습니다.
- 이름, 전화번호, 생년월일은 받지 않습니다.
- 비밀번호는 Google Firebase Authentication이 암호화해 보관합니다. 회사는 비밀번호를 볼 수 없습니다.
- 메모는 자유롭게 쓰는 칸입니다. 민감한 개인정보는 메모에 쓰지 않기를 권합니다.

### 나. 서비스 이용 중 자동으로 생성·수집되는 정보

| 항목 | 수집 도구 |
|---|---|
| 계정 식별자(익명 계정 포함), 가입·최근 로그인 일시 | Firebase Authentication |
| 앱 이용 기록(앱 실행, 로그인, 가입 안내 노출·선택 등 이벤트), 앱 인스턴스 ID, 기기 모델·OS·앱 버전·언어, IP 주소로 추정한 대략적 지역 | Google Analytics for Firebase |
| 광고 ID(Android 기기에 한함) | Google Analytics for Firebase |
| 오류 발생 기록(오류 내용, 발생 시각, 기기 모델·OS·앱 버전, 설치 식별자) | Firebase Crashlytics |

- 회사는 계정 식별자를 Google Analytics의 사용자 ID로 씁니다. 이메일 주소는 Google Analytics에 보내지 않습니다.
- 광고 ID는 광고에 쓰지 않습니다. 서비스에는 광고가 없습니다.
- iOS에서는 앱 추적 투명성(ATT) 권한을 요청하지 않습니다. 그래서 iOS 광고 식별자(IDFA)를 수집하지 않습니다.

### 다. 기기 권한

| 권한 | 목적 | 필수 여부 |
|---|---|---|
| 카메라 | 책 뒤표지의 ISBN 바코드를 읽습니다. | 선택 |

- 카메라 영상은 기기 안에서 바코드를 읽는 데만 씁니다. 회사는 영상을 저장하거나 전송하지 않습니다.
- 카메라 권한을 허용하지 않아도 제목 검색이나 직접 입력으로 책을 추가할 수 있습니다.

## 3. 보유·이용 기간과 파기

### 가. 보유·이용 기간

| 항목 | 기간 |
|---|---|
| 이메일 주소, 계정 식별자, 독서 기록 | 회원 탈퇴 시까지 |
| 익명 계정과 그 독서 기록 | 이용자가 삭제를 요청하거나 탈퇴할 때까지 |
| 앱 이용 기록(Google Analytics) | Google Analytics 데이터 보존 기간 설정에 따라 자동 삭제 |
| 오류 기록(Firebase Crashlytics) | 수집일부터 90일 |

- 앱을 지우거나 다른 계정으로 로그인하면, 이용하던 익명 계정에 다시 접근할 수 없습니다. 그 계정의 기록은 서버에 남습니다. 삭제를 원하면 아래 [5. 정보주체의 권리](#5-정보주체의-권리와-행사-방법)의 방법으로 요청해 주세요.
- 법령이 보관을 요구하는 개인정보는 현재 없습니다.

### 나. 파기 절차와 방법

1. 이용자가 앱에서 회원 탈퇴를 하면, 앱이 서버의 독서 기록 전체와 계정을 바로 삭제합니다.
2. 같은 때 앱은 기기에 저장된 설정 값도 삭제합니다.
3. 이메일로 삭제를 요청하면, 회사는 본인임을 확인한 뒤 지체 없이 삭제합니다.
4. 전자 파일은 복구할 수 없는 방법으로 삭제합니다. 회사는 개인정보를 종이로 출력해 보관하지 않습니다.

## 4. 제3자 제공, 처리 위탁과 국외 이전

### 가. 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 법령에 특별한 규정이 있으면 예외로 합니다.

### 나. 처리 위탁과 국외 이전

회사는 서비스 운영을 위해 아래와 같이 개인정보 처리를 위탁하며, 이에 따라 개인정보가 국외로 이전됩니다.

| 구분 | 내용 |
|---|---|
| 이전받는 자 | Google LLC (Google Firebase) |
| 연락처 | [Google 개인정보처리방침](https://policies.google.com/privacy), [Firebase 개인정보 보호](https://firebase.google.com/support/privacy) |
| 이전 국가 | 미국 등 Google이 운영하는 데이터센터 소재 국가 (독서 기록 데이터베이스는 미국에 있습니다) |
| 이전 일시와 방법 | 서비스를 이용할 때마다 네트워크로 전송합니다. |
| 이용 서비스와 이전 항목 | Firebase Authentication: 이메일 주소, 비밀번호, 계정 식별자, 가입·로그인 일시 / Firebase Realtime Database: 독서 기록 전체(2-가의 독서 기록 항목) / Google Analytics for Firebase: 2-나의 앱 이용 기록과 광고 ID / Firebase Crashlytics: 2-나의 오류 기록 |
| 이용 목적 | 계정 인증, 데이터 저장, 이용 통계 분석, 오류 분석 |
| 보유·이용 기간 | 3-가의 기간과 같습니다. 위탁 계약이 끝나면 파기합니다. |

**국외 이전을 거부하는 방법과 결과**

- 서비스는 위의 Google 서비스 없이는 동작하지 않습니다. 그래서 국외 이전만 따로 거부할 수는 없습니다.
- 국외 이전을 원하지 않으면, 서비스 이용을 중단하고 회원 탈퇴를 해 주세요.
- 탈퇴하면 저장한 독서 기록이 모두 삭제되고 서비스를 이용할 수 없습니다.

### 다. 책 검색 서비스 이용

책을 검색하면, 앱이 아래 서비스에 검색어(책 제목) 또는 ISBN을 직접 보냅니다. 이메일 주소와 계정 식별자는 보내지 않습니다. 다만 인터넷 통신의 특성상 기기의 IP 주소가 각 서비스에 전달됩니다. 검색 결과의 표지 이미지도 각 서비스의 서버에서 불러옵니다.

| 서비스 | 운영 주체 | 소재 국가 |
|---|---|---|
| 카카오 책 검색 | 주식회사 카카오 | 대한민국 |
| ISBN 서지정보 | 국립중앙도서관 | 대한민국 |
| Open Library | Internet Archive | 미국 |

## 5. 정보주체의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보를 열람, 정정, 삭제하거나 처리 정지를 요구할 수 있습니다.

**앱에서 직접 하는 방법**

- 열람·정정: 책장, 기록, 메모 화면에서 내용을 보고 고칠 수 있습니다.
- 삭제: 책, 기록, 메모를 각각 삭제할 수 있습니다.
- 비밀번호 변경: 설정 → 이메일 계정 항목 → 비밀번호 설정/재설정
- 회원 탈퇴(이메일 계정): 다음 순서로 진행합니다.
  1. 설정 탭을 엽니다.
  2. 이메일 주소가 표시된 항목을 누릅니다.
  3. 회원탈퇴를 누릅니다.
  4. 확인을 누릅니다.
  5. 비밀번호를 입력합니다.
- 익명 계정 삭제: 익명 계정에는 탈퇴 메뉴가 없습니다. 먼저 이메일로 가입하면 기록이 그 계정으로 이어집니다. 그다음 위의 회원 탈퇴 순서를 따르면 모든 기록이 삭제됩니다.

**이메일로 요청하는 방법**

- 아래 [8. 개인정보 보호책임자](#8-개인정보-보호책임자)의 이메일로 요청할 수 있습니다.
- 회사는 요청자가 본인인지 확인한 뒤 지체 없이 처리하고 결과를 알려 드립니다.
- 법정대리인이나 위임을 받은 사람도 요청할 수 있습니다. 이때는 위임 사실을 확인할 수 있는 자료가 필요합니다.

## 6. 안전성 확보 조치

회사는 개인정보를 보호하기 위해 아래 조치를 합니다.

1. 앱과 서버 사이의 모든 통신은 HTTPS로 암호화합니다.
2. 비밀번호는 Firebase Authentication이 암호화해 저장합니다. 회사도 비밀번호를 볼 수 없습니다.

## 7. 자동 수집 장치의 설치·운영과 거부

- 서비스는 모바일 앱이며 쿠키를 쓰지 않습니다.
- 서비스는 2-나의 정보를 자동으로 수집하기 위해 Google Analytics for Firebase와 Firebase Crashlytics를 씁니다.
- 앱 안에는 이 수집을 끄는 설정이 없습니다. 수집을 원하지 않으면 서비스 이용을 중단해 주세요.
- Android에서는 광고 ID를 직접 관리할 수 있습니다: 기기 설정 → Google → 광고(또는 개인 정보 보호 → 광고) → 광고 ID 삭제 또는 재설정
